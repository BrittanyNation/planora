# Planora

A fully functional brand campaign site for Planora, a fictional visual planning tool for small creative teams. Original portfolio work by Brittany Nation. Planora is not a real product and no affiliation is claimed.

Live site: https://brittanynation.github.io/planora/

## What this project shows

Built to support applications for Brand Designer, Junior Copywriter, and Front End Developer roles. The site carries a full brand voice in real copy, not filler: a campaign headline, plain language product explanation, pricing copy with honest math, and a demo offer written end to end. The front end is hand built in HTML, CSS, and JavaScript with every interactive element working.

## Features

Home: feature tabs for Plan, Track, and Share that switch panels, a working board demo with three columns where cards can be added, moved forward or back, and removed, with the board count computed live and the board saved in localStorage, a testimonial carousel with previous and next controls, and a Friday letter signup with validation and duplicate recognition.

Pricing: a monthly and yearly billing toggle where yearly prices are computed live at twenty percent off the monthly base, a billed yearly total shown on each card, plan choice buttons that store the chosen plan, a comparison table, and FAQ accordions that keep one answer open at a time.

Book a demo: a validated request form for name, work email, company, team size, plan, and a demo date that cannot be in the past. The plan chosen on the pricing page prefills here. A valid request ends in a confirmation with a generated PN reference and the request saved in localStorage. The page states honestly that this portfolio version saves requests in the browser only.

## Course note

This is a post course combined skills build. The Full Stack Web Development Bootcamp track in this portfolio finished its five steps in early November 2026. This build reuses its front end patterns in plain JavaScript, commented as study code: data driven rendering, state with localStorage persistence, and derived state where totals, counts, and displayed prices are computed rather than stored.
